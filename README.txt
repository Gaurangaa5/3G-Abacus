Virtual 3G Abacus — Completely Offline
==========================================

Open index.html directly by double-clicking it.

No server, Node.js, npm, or internet connection is required.

Fonts:
- Muli.ttf
- Muli-Bold.ttf

Keep those two font files beside index.html.

Solve mode:
- Starts with exactly 2 numbers.
- Use ＋ Add Number to add more terms.
- Every operator is a dropdown (+ / -).
- Example: 32 + 4 + 7 - 7
- Start Solution creates step-by-step states.
- Next Step moves the abacus to the next state.
- Previous Step moves the abacus back.
- The beads visibly animate on every step.
